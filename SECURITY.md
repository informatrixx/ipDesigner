# Sicherheitshinweise

IP Designer ist ein internes Planungswerkzeug und bringt keine eigene Benutzerverwaltung mit. Veröffentliche den Dienst nicht ungeschützt im Internet. Setze mindestens einen abgesicherten Reverse Proxy, VPN-Zugriff oder nginx-Authentifizierung davor.

Sicherheitsprobleme bitte nicht als öffentliche Issue mit Details melden. Für dieses zunächst private Solo-Repository genügt eine vertrauliche Nachricht an den Repository-Eigentümer. Keine produktiven SQLite-Dateien, Passwörter, Tokens oder personenbezogenen Daten in Issues, Pull Requests oder Commits ablegen.
